# UE1208 - Web 1

Bienvenue dans ce guide complet pour apprendre la programmation web (côté client) ! Ce cours vous accompagnera progressivement depuis les bases du HTML jusqu'aux concepts avancés de JavaScript.

## 🌟 Commencer par les fondamentaux

**Nouveau dans la programmation web ?** Commencez par lire notre [Introduction générale à la programmation web](/introduction-generale) qui vous expliquera les concepts fondamentaux, la philosophie du développement web moderne et l'écosystème dans lequel vous allez évoluer.

Cette introduction vous aidera à comprendre :
- Pourquoi HTML, CSS et JavaScript forment un trio indissociable
- Comment ces technologies s'articulent pour créer des expériences web
- Les principes de l'accessibilité et du design inclusif
- L'importance de la performance et de l'expérience utilisateur
- Le mindset du développeur web moderne

## 🎯 Objectifs du cours

- Maîtriser les fondamentaux du HTML pour structurer des pages web
- Apprendre CSS pour styliser et animer vos interfaces
- Développer des compétences en JavaScript pour créer des sites interactifs
- Découvrir les bonnes pratiques du développement web moderne

## 📚 Structure du cours

Ce cours est organisé en 13 chapitres suivant une progression logique :

### 🏗️ Fondations
1. **Fondamentaux HTML** - Structure et sémantique
2. **Formulaires HTML** - Interaction utilisateur
3. **Fondamentaux CSS** - Styles et mise en page

### 🎨 Interface et Design
4. **Navigation et Menu** - Navigation utilisateur
5. **Animations et Transitions CSS** - Effets visuels

### ⚡ Programmation
6. **Fondamentaux JavaScript** - Syntaxe et logique
7. **JavaScript et DOM** - Manipulation des éléments
8. **Gestion des Événements** - Interactivité

### 🚀 Concepts Avancés
9. **Programmation Interactive** - Jeux et interactions
10. **Interface Utilisateur Avancée** - Composants dynamiques
11. **Programmation Asynchrone** - API et requêtes
12. **Stockage Local** - Persistance des données
13. **Qualité et Bonnes Pratiques** - Code professionnel

## 🚀 Comment utiliser ce cours

1. **Suivez l'ordre** : Les chapitres sont conçus pour s'appuyer les uns sur les autres
2. **Pratiquez** : Chaque concept est accompagné d'exemples pratiques
3. **Expérimentez** : N'hésitez pas à modifier les exemples pour mieux comprendre
4. **Progressez à votre rythme** : Prenez le temps de bien assimiler chaque notion

## 🛠️ Prérequis

- Aucune expérience préalable en programmation requise
- Un navigateur web moderne (Chrome, Firefox, Safari, Edge)
- Un éditeur de code (VS Code recommandé)
- Motivation et curiosité ! 🎉
